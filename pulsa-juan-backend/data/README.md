# data

`regions.json`: Indonesian provinces, regencies (kabupaten/kota) and districts
(kecamatan) for the sign-up "Daerah Domisili" picker. Built by
`scripts/build-regions.mjs` from [idn-area-data](https://github.com/fityannugroho/idn-area-data)
(Open Database License 1.0). Rebuild after bumping that package.
